# Movies Explorer

Movies Explorer helps you find films, save movies for later, and keep track of what you have watched.

## Features

- Browse popular movies from TMDB.
- Search for movies by title.
- Add movies to your watchlist without duplicates.
- Mark watchlist movies as watched.
- Keep your saved movies after refreshing the page with `localStorage`.
- See loading, error, no-results, and missing-poster messages.

## Built with

- React and JavaScript
- Vite
- Tailwind CSS
- React Router
- The Movie Database (TMDB) API
- Browser `localStorage`
